# 09 Particle Effect

In this chapter, we will add a particle effect to the tap phase's hit event.

## Existing Particle

The shared `Particles` class already declares the standard cyan circular tap particle from play mode. This code is for
reference; do not edit `guide/lib/particle.py`:

```python
from sonolus.script.particle import StandardParticle, particles


@particles
class Particles:
    # ...

    note: StandardParticle.NOTE_CIRCULAR_TAP_CYAN
```

## Particle Effect

In `guide/tutorial/note.py`, add this import with the other guide imports:

```python
from guide.lib.particle import Particles
```

Then replace `play_note_hit_effects` with:

```python
def play_note_hit_effects():
    layout = Rect.from_center(
        Vec2(0, 1),
        Vec2(4 * Config.note_radius, -4 * Config.note_radius),
    )
    Effects.perfect.play()
    Particles.note.spawn(layout, duration=0.3)
```

The particle uses the same transformed coordinate system as the skin, so setting its center to `Vec2(0, 1)` places it on
the judgment line.

## Checkpoint

Validate the completed tutorial from the project directory:

```shell
uv run sonolus-py check --tutorial
```

Open the tutorial. Confirm that:

- The judgment line remains visible throughout the phase.
- The note appears enlarged, falls to the judgment line, and freezes there with the tap text and animated hand.
- The sound and particle play once when the frozen range ends.
- A one-second blank pause follows the hit, and then the phase restarts.
- Either navigation button restarts the phase immediately.

When these checks pass, rebuild the complete project with the finished tutorial:

```shell
uv run sonolus-py build
```

To add another note type later:

1. Declare any new instruction resources in `guide/tutorial/instructions.py` and shared visual or audio resources in
   the corresponding `guide/lib` files.
2. Add the drawing functions and phase function to `guide/tutorial/note.py`.
3. Add a current phase index to `PhaseState` in `guide/tutorial/navigate.py`. In `navigate`, use
   [`navigation_direction`](https://sonolus.py.qwewqa.xyz/reference/sonolus.script.runtime/#sonolus.script.runtime.navigation_direction)
   to change and wrap that index before resetting the phase clock.
4. Update `guide/tutorial/update.py` to run the phase selected by that index.

These extensions are not required for the completed tap tutorial.
